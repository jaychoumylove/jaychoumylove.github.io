    字体

    • 斜体

      在你要倾斜的字体左右用一个*包起来;

    • 加粗

      在你要加粗的字体左右用两个*包起来;

    • 斜体加粗

      没错，用三个*包起来的字体即可斜体加粗;

    • 删除线

      在你要删除线的字体左右用两个~包起来;
