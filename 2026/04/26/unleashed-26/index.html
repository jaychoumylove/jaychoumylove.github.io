昨天带着 MacBook 回了一趟家，本意是打算用 MacBook 接上外接显示看看里面都存了啥子东西的，我还剩多少资料可以供我续命的。不过说回来，现在都 A 编程了，学这些资料作有多少都是问号，有一点算一点吧。一开始接上外接显示怎么也不起作用，外接显示器始终没有响应，只能给 mac 干充电，以前也出过这个显示屏失灵的情况，不过那是多年前的事情了，现在我的当务之急是尽快回血。

  • 一是自己的能力回血，只有能力上来了才更有机会找到吃饭的活啊。
  • 二是找回以前的账号，目标一更快的实现

话又说回来，我现在连最基本的账号都没有。

  • 没有身份证： 连最基础的身份登记都做不了，意味着我不能租房，不能大额消费，连最简单的人脸识别都做不了，所以很多场景下我都是四个字“寸步难行”
  • 没有银行卡：就是没钱，呐，没钱寸步难行，连我去办理身份证都要我微信扫码支付，我就奇了怪了，我连身份证都没有，怎么有微信，更别说有银行卡了
  • 没有各类社交账号：如微，支付宝，酷狗都没有，这在以前是要我命的存在了，但是现在也只能被动的接上这些事实。

说起来，我还是只能先恢复身份（我是谁？），然后恢复银行卡（我能干嘛？），之后恢复各类社交账号（快速恢复自己以前的编程能力），最后把自己之前的装备不说完全复原，但起码有与之相比有差不多的替代品吧，反正就是不能和之前差太多，以前唾手可得的，如今却是求之不得啊。在做这三件事情的同时，我还得把自己的能力尽可能的提高。

想着想着，我把 mac 的盖子一翻开，居然看见屏幕闪了一下，嗯？屏幕没有坏，我试着把锁屏解了，然后简单的又关上，翻开，如此反复，都没有反应。吃完饭之后，我慢慢翻开盖子，屏幕居然亮了，我赶忙把锁屏解了，看着自己以往的 code 之后内心掀起波澜，我看了自己写的代码，很多我都看不懂，我在最后那年写的是 js、ts、node，前面写的 php 就有些年头了。但是很多项目我自己都启动不了，算了，慢慢来吧。我当时就去玩之前的游戏 FM、TM 了。

今天下到水口之后，我把电脑打开，把 wifi 连上，很多账号都没办法登录。

  • 微信： 账号或密码错误，尝试找回账号，人脸验证失败。后面我验证通过了，又让我验证银行卡，我试了好几张卡，都验证失败，也是，我的银行卡都没激活呢，里面的业务还要一一重新办理。
  • QQ：账号许久未登录，已进入保护模式，需要用原设备验证
  • youku：虽然要我验证但是我起码知道账号密码了。我后续只要改绑就可以了。
  • 163：按理说，这是我最熟悉的了，账号密码都晓，但还是要用绑定手机验证。

而让我感到惊喜的是，我的百度云盘居然可以登录，同时登录的还有酷狗！还有 google.postman，我重新打开了网盘里面的照片，视频。听了酷狗里面收藏的歌单，虽然这些在几年后，发生了些许变化，但是，熟系的感觉来临时还是让我激动不已。等了好久终于来了。而且，我可以看密码本了，这样我恢复的账号又多了许多。

于是我这个下午都在升级 mac，把该更新的软件更新。一边尝试恢复一些账号，一边看看现在的编程环境，感受自己的技术能力。

晚上吃饭时，堂姐一直就给我上发条：

  • 会做饭么？
  • 会做菜吧。
  • 骑车呢？
  • 以前上班的时候怎么没考驾照啊？
  • 想吃什么啊？
  • 会去买菜吧
  • 中午吃完饭，会洗碗吧。
  • 人呢，不是只有工作的，还要生活啊。

这，怎么说呢？我全都不会，但是人在屋檐下，我努力让自己不那么尴尬，满口答应。我自己是完美主义者，在工作上都会给自己上发条，姑且就利用这个机会好好生活吧。毕竟还有十几天的时间。我在堂姐他们眼中都是傻子一样的，各种行为中，只要我俩眼神交汇，我都尴尬不已，甚至我在背后都能感受到她那鄙夷杀人拌的眼光。唉，以前印象不好改观了。

随便说一下我连在命令行建一个文件都不知道，后需要更新博客但是，我也要重新配置 GIT，这现在又是一个我的盲点。

请我一杯咖啡吧！
