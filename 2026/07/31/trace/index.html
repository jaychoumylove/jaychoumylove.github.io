这个世界是冗余的，膨胀的。

一时有感而发，遂记下。

我曾也是个码农，还是最低级的那种，对，就是那个全世界最好的语言编程师。常年为搬砖而生，日常的工作是不断地给公司呈上活动的解决方案，也就是说不断地写 bug，再修正，然后再修正，然后就没有然后了，大概活动的时间到这里就结束了。我那段时间的内心活动 belike：

  • 这活动谁设计的？
  • 这有人会进来么？
  • 怎么又有活动？上个活动 3 天前才结束，写这个活动，那上个活动的 bug 不用修了吧？嗯。

每天上午和策划撕逼，和 UI 对细节，和客服整用户反馈，和测试复现 bug，对，你没看错我上午几乎没有在编程，如果有的话，那就是我的 deadline 要来了，原计划靠边站。下午进入疯狂模式，因为上午已经把各方面的需求都弄清晰了，接下来就是表演时间了，树立结构，构建逻辑，细节优化，衔接测试，部署上线，一个下午全搞定，你没看错一个全新的活动(甚至一个全新的模块，比如他们要加一个宠物到产品里面去)就这样成型且上线了，天哪，而且程序只有我一个人在编写，你问我是怎么做到的，嘿嘿，我也觉得不可思议啊，完成的瞬间我感觉我可以又一次提起加薪的请求了。然而梁静茹给我的勇气没能持续到第二天，因为那时测试就会发出连串的 bug，浇灭了我的斗志。于是上午就这样在开会和撕逼的气氛中莫名的过去了，下午开始新一轮的战斗。
大致每天的工作状态就是这样子，于是可以知道写出来，哦不，复用出来的程序多多少少都有 bug，甚至修复的时候你发现有两个一摸一样的function，不过你真的敢去动它么，或者说你发现又有一个模块需要复用这个逻辑的时候，你敢复用么？稍稍control+F一下，发现有 N 个代码块一样或者复用了，你的头不大么？更有甚者，各种魔法数字在其中穿插，让你目不暇接的同时还可以打击你的心智，我的神呐！
所以我在上班的时候怀念昨晚，自然地畅想着今晚，在工作日期盼休息日。我感觉自己像个牛马一样，对，努力且搞笑，哦不，是高效的牛马。当然的你会嘲讽：写成shit那样还好意思说自己高效？搞笑吧。是的，我每天写着shit，之后的每一天还不断在持续输出，但我依然认为我是高效作业的，我也很清楚，如果正经的写一个那样的模块需要的气力和时间，而在我看来写出一个，符合活动业务的代码结构，且语句简单，逻辑清楚，结构优雅，可拓展性高，维护方便的代码，估计在 deadline 那一天只够写出业务量的 1/2，3/4 顶天了，当然，这种代码一般一写出来，基本测试都是一路通关的，如果策划和 UI 不临时改需求的话，如果有那就做好重写业务代码的准备吧。而且活动的内容千变万化，你完全不知道它下一个活动的业务是什么。在我看来，公司某种程度上在内耗我。而在策划看来，公司在内耗他。在公司的角度，要活着就要经得起市场的考验。某种程度上，我们都是时代的苦主，在崩溃的边缘疯狂试探，也许在某个尚未搞清楚状况的时刻爆发。我在每个不能入眠的夜晚想的都是我活着的意义，我活着又是为了什么，如果我真的像一个胶水工一样粘稠着各种业务，那，我又活成了什么了。
我知道自己不能再这样下去了，我想要脱离内耗。但是当下的我并没有改变的力量，勇气，时机。我每天应付完工作之后就是身心俱疲的状态，完全提不起给自己提升的那股气。我试着给自己下了一个任务，用一个陌生的的框架做自己想做的东西。试着证明一些自己身上的特质，就像那些旅游的游客，看演唱会的观众，吃饭前的食客，拍照，证明自己来过，体验过。我在之后的很多时候也是这么做的。然而，良知告诉我这些都没有人知道，也没有多少人关注。但我至少做了。
然而改变我的是我回到乡下时看到的一副场景。乡间的垃圾成堆，买了乡下街道的一瓶饮料，几个月就快过期了。而我回到家后，家里的情况和我想象中的大不一样了，很多房屋没有人住了，乡间的人们都搬到了附近较大的镇子去了，以前一些大户花了大价钱建的房子被废弃。就像我家一样，花了不少钱安定的家，现在要去镇上住了，这里也即将废弃，恍惚半生，为谁辛苦为谁甜呢？我打开手机，指尖划过一些以前的数据，现在很多都没有人关注了，或者说，它被冗余了。
也许我们的理想都是美好的，而现实是那么的残酷，人类的产出不断的冗余，不断地膨胀。
